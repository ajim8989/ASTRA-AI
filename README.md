# ASTRA AI

ASTRA AI is a modern AI workspace built with **Next.js 15**,
**TypeScript**, **Tailwind CSS**, and a modular architecture.

## Features

-   🔐 Authentication
-   💬 AI Chat Workspace
-   🔍 Deep Research
-   💻 Code Studio
-   🤖 AI Studio
-   📄 Documents
-   📁 Projects
-   📅 Calendar
-   ✅ Tasks
-   👥 Team Workspace
-   🔔 Notifications
-   ⚙️ Settings & Profile

## Tech Stack

-   Next.js 15
-   React
-   TypeScript
-   Tailwind CSS
-   Zustand
-   Axios

## Getting Started

``` bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Environment Variables

Create `.env.local`:

``` env
NEXT_PUBLIC_API_URL=http://localhost:8080
NEXT_PUBLIC_APP_NAME=ASTRA AI
```

## Build

``` bash
npm run build
npm start
```
